# VR Language Assistant with MR Passthrough & Micro-Gesture

**Description**  
This Unity project implements a real-time mixed-reality language assistant on Meta Quest Pro/Quest 3 using:
- OpenAI API (LLM + Whisper STT)  
- WIZ.AI multilingual voice processing  
- Passthrough Camera SDK  
- Micro-gesture fingertip tracking  
Supports multiple languages (e.g., English, Spanish, Chinese, Portuguese, Tagalog).

**Key Features**  
- Real-time voice-to-text transcription and LLM reasoning  
- Passthrough camera capture of user environment + contextual grounding (object names, signage)  
- Hand micro-gesture controls for intuitive interaction  
- Multilingual voice input and output
